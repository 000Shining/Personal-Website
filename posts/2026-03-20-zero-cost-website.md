## 为什么要建个人网站

在求职市场中，个人网站是最直接的数字名片。相比于第三方平台：

- 100% 内容控制权
- 无广告、无推荐算法干扰
- 完全自定义设计风格
- 一次搭建，长期受益

## 技术选型

### 为什么选择纯静态

| 方案 | 优点 | 缺点 |
|------|------|------|
| 纯静态 | 零成本、高性能、易维护 | 无动态功能 |
| WordPress | 功能丰富 | 需要服务器、维护成本高 |
| Next.js | 现代开发体验 | 学习曲线陡峭 |

对于个人展示网站，纯静态完全够用。

## 搭建步骤

### 1. 设计页面结构

先想清楚需要哪些页面：
- 首页（入口 + 导航）
- 文章列表 + 详情
- 作品展示
- 关于我

### 2. 编写代码

使用原生三件套：HTML 结构 + CSS 样式 + JS 交互。

### 3. 部署到 GitHub Pages

```bash
git add .
git commit -m "Initial commit"
git push origin main
```

然后在仓库 Settings → Pages 中启用即可。

### 4. 绑定自定义域名（可选）

在域名 DNS 中添加 CNAME 记录指向 `username.github.io`。

## 维护

- 新文章：写 Markdown → 更新 JSON 索引 → push
- 样式调整：修改 CSS → push
- 零运维成本

## 总结

个人网站是技术人员的名片，也是最好的实践项目。从零搭建一个网站，你会学到前端基础、Git 操作和部署流程。投入一个周末，收获一个永久的数字资产。
