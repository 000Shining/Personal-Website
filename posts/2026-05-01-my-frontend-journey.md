## 起步阶段

最初接触前端是从 HTML 和 CSS 开始。那时候连什么是"标签"都不知道，只是照着教程一行一行地敲代码。

### 第一个项目：个人主页

做了一个简单的个人主页，学会了基本的布局和样式。虽然现在看来那个页面很简陋，但它让我第一次感受到了"创造"的乐趣——写几行代码，浏览器里就能出现一个页面。

### 遇到的困难

跨浏览器兼容性是一个挑战。同样的 CSS，在 Chrome 和 IE 上表现完全不同。那时候花了大量时间查 MDN 文档和 Stack Overflow。

## 进阶学习

后来开始学习 JavaScript，理解了 DOM 操作和事件处理。然后又接触了 React 框架，组件化开发的思想彻底改变了我的编程方式。

### React 带来的改变

- 组件化：把 UI 拆分成独立的、可复用的组件
- 声明式：描述 UI 应该是什么样子，而不是一步步操作 DOM
- 状态管理：理解了 state 和 props 的区别

> "The best way to learn is to build." —— 这是我最大的体会。看十遍教程不如自己动手做一遍。

## 现在的状态

现在可以独立完成从前端到部署的全流程开发。这篇文章所在的个人网站，就是我用原生 HTML/CSS/JS 从零搭建的。

### 技术栈总结

| 层级 | 技术 |
|------|------|
| 结构 | HTML5 语义化标签 |
| 样式 | CSS3 Flex/Grid + CSS 变量 |
| 交互 | Vanilla JavaScript (ES6+) |
| 渲染 | marked.js (Markdown → HTML) |
| 部署 | GitHub Pages |

### 下一步计划

1. 深入学习 TypeScript
2. 探索 Next.js 和 SSR
3. 贡献开源项目

## 写在最后

前端是一条不断学习、不断迭代的路。新框架、新工具层出不穷，但底层的基础——HTML、CSS、JavaScript——始终是核心。打好基础，剩下的都是锦上添花。
